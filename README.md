About

AGU CRYPTO ANALYZER is an independent cryptocurrency market analysis application designed to help users understand market movements through technical indicators, market prices and trading alerts.

Current Features

- Live cryptocurrency market prices.
- Spot market analysis.
- USDT-M Futures market analysis.
- RSI indicator.
- EMA 20, EMA 50 and EMA 200.
- MACD indicator.
- ATR volatility calculation.
- Basic support and resistance levels.
- BUY, SELL and WAIT analysis labels.
- Illustrative entry, stop-loss and take-profit levels.
- Browser notifications where supported.
- Sound alerts.
- Basic offline application caching.
- Mobile-friendly interface.

Supported Assets

BTC, ETH, BNB, SOL, XRP, DOGE, ADA, AVAX, LINK and TON.

Technology

- HTML
- CSS
- JavaScript
- Binance public market-data endpoints
- Service Workers
- Web App Manifest

Deployment

This project can be hosted using GitHub Pages.

1. Open repository Settings.
2. Select Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select the main branch.
5. Select the root folder.
6. Save.
7. Wait for GitHub Pages to publish the website.

Important Limitations

This is an initial prototype.

It does not currently include:

- Secure user registration and authentication.
- Verified Premium subscriptions.
- Payment processing.
- Server-side analysis limits.
- Advanced AI integration.
- Reliable background push alerts.
- Comprehensive historical backtesting.
- Independently verified trading performance.

The four-analysis limit is stored in the user's browser and can be reset. It is not a secure membership control.
